# 레슨 × 기출 해설 연결 기획안

## 0. 한 줄 요약
레슨은 "처음 배우는 자리"라서 해설 전체를 그대로 넣으면 무거워요.
**레슨에서 배운 내용이 실제 시험에서는 어떻게 나오는지 짧게 보여 주고, 틀렸을 때만 깊게 보여 주는 방식**으로 넣어요.

## 1. 지금 상태 (데이터 확인 결과)
| 항목 | 수치 |
|---|---|
| 레슨이 있는 스킬 | 211개 (그중 해설이 있는 스킬 208개) |
| 레슨 1개당 카드 | 평균 6.4장 (최소 4, 최대 13) |
| 레슨 1개당 구간(제목 있는 설명 카드) | 평균 2.8개 |
| 스킬 1개당 연결 가능한 해설 | 평균 9개 (OX 위주, 선택형은 평균 2.3개) |
| 선택형 해설이 하나도 없는 레슨 | 124개 → OX 해설로 채워야 함 |
| 해설 별점 분포 | ★2: 87 · ★3: 833 · ★4: 792 · ★5: 194 |
| 오류 의심(er) 표시 해설 | 8개 → 레슨에는 넣지 않음 |

레슨 문제 카드(OX·빈칸·고르기·짝맞추기)에는 지금 **한 줄짜리 해설(`e`)만** 있고, 기출 해설과는 연결 고리(id)가 없어요.
그래서 **어느 레슨 카드가 어느 기출 해설과 같은 개념인지 짝을 지어 주는 작업**이 핵심이에요. 이 작업에 아래 프롬프트를 써요.

## 2. 레슨에 넣는 4가지

### ① 구간 끝 "시험에선 이렇게 나와요" 카드 (레슨당 최대 2장)
- 설명 구간이 끝나는 자리에 **실제 기출에서 만든 OX(또는 선택형) 한 문제**를 넣어요.
- 답을 고르면 **짧은 해설**만 보여요: 핵심 단서 + 한 줄 기억법 + 별점.
- 이유·바른 문장·비교표는 "자세히 보기"를 눌러야 펼쳐져요.
- 조건
  - 그 앞 구간에서 **이미 배운 내용만으로 풀 수 있는 문제**만 넣어요.
  - ★4 이상을 우선하고, 오류 의심(er) 문항은 빼요.
- 효과: 배운 직후 "이게 실제 시험 문제구나"를 체감해요.

### ② 레슨 문제를 틀렸을 때 "왜 그럴까?" 펼치기
- 레슨 카드를 틀리면 지금처럼 한 줄 해설이 먼저 나와요.
- 그 아래에 **같은 개념의 기출 해설 중 이유·한 줄 기억법·비교표**만 접어서 붙여요.
- 맞힌 사람에게는 보이지 않아요. 흐름이 끊기지 않게 하려는 거예요.

### ③ 레슨 끝 화면 "시험 포인트 TOP 3" + "헷갈리는 짝"
- 지금 있는 "시험에 나오는 한 줄"을 바꾸거나 보강해요.
  - 이번 레슨과 연결된 해설의 **한 줄 기억법 중 별점 높은 3개**
  - 해설의 비교표 중 **이 레슨 내용과 맞는 표 1개**
- 레슨을 마치는 순간에 바로 외울 거리를 남겨요.

### ④ "연습 문제로 굳히기"에 기출 문항 섞기
- 레슨 직후 연습 10문제 중 2~3문제를 **이번 레슨과 연결된 기출 문항**으로 채워요.
- 해설 모드(바로 해설)로 풀어요.
- 틀리면 기존 오답노트에 자동으로 담겨요.

## 3. 넣지 않는 것 (원칙)
- **레슨에 새 사실을 추가하지 않아요.** 이미 검수한 레슨 문장과 기출 해설 문장만 써요.
- 다리 역할 문장("방금 배운 ○○이 시험에선 이렇게 나와요")에는 사실을 담지 않아요.
- 기출 원문은 넣지 않아요. 지금처럼 다시 쓴 문항만 써요.
- 레슨 1개 길이는 최대 +2장까지만 늘려요. 지금 평균이 6.4장이라 8장을 넘지 않게 해요.
- 레슨에서 다루지 않은 개념이 기출 해설에 많이 나오면 레슨에 끼워 넣지 않아요.
  - `gaps` 목록으로만 남겨요. 레슨 보강이 필요한지는 운영자(임유신)가 보고 결정해요.

## 4. 작업 흐름
1. **수집 스크립트**: 스킬마다 아래 자료를 묶어 프롬프트 입력을 만들어요.
   - 레슨 카드 전체(번호 포함)
   - 그 스킬의 기출 해설 목록(id, 문제, 핵심 단서, 한 줄 기억법, 별점, 비교표 제목, er 여부)
2. **프롬프트 실행**: 아래 프롬프트로 스킬마다 연결 JSON을 받아요.
3. **검증 스크립트**: 아래 항목을 자동 검사해요.
   - id가 실제로 있는지, 그 스킬의 문항인지
   - er 문항이 끼었는지
   - 장 수 제한을 지켰는지
   - `after` 위치가 맞는지
   - `lead` 길이가 맞는지
   - 출력에 해설에 없는 숫자나 용어가 새로 등장하는지
4. **주입**: `<script id="lxl">` 데이터로 앱에 넣어요. 레슨 화면에는 카드 종류 `xq`와 틀렸을 때 펼치기를 추가해요.
5. **시범 적용**: 2단원(해부학) 레슨 10개만 먼저 넣어서 보여 드리고, 검사를 받은 뒤 전체로 넓혀요.
6. **효과 측정**: 관리자 통계에 아래를 추가해요.
   - 레슨 완료율(전/후)
   - "시험에선" 카드 정답률
   - 레슨 후 연습에서 기출 문항 정답률

## 6. 프롬프트 (스킬 1개마다 실행)

```
# 역할
당신은 물리치료사 국가시험 학습 앱의 콘텐츠 편집자다.
이미 검수가 끝난 "레슨 카드"와 "기출 해설"을 서로 연결해서,
레슨을 듣는 학생이 배운 직후 실제 시험에서 어떻게 나오는지 체감하게 만드는 것이 목표다.
새 내용을 쓰는 사람이 아니라, 있는 자료를 골라 배치하는 사람이다.

# 입력
## 스킬
{sid} · {skill_name} · 단원 {unit}
## 레슨 목표
{goal}
## 레슨 카드 (번호: 종류 · 제목 · 본문/문제 · 정답 · 한 줄 해설)
{lesson_cards}
## 기출 해설 목록 (id · 종류 · 문제 · 정답 · 핵심 단서 · 한 줄 기억법 · 별점 · 비교표 제목 · 오류의심)
{xpl_list}

# 할 일
1. exam_cards: 레슨 중간에 넣을 "시험에선 이렇게 나와요" 문항을 0~2개 고른다.
   - after = 이 문항을 넣을 위치(레슨 카드 번호). 그 번호까지의 카드가 이 문항을 푸는 데 필요한 내용을 모두 가르쳤어야 한다.
   - 서로 다른 구간에서 고르고, 같은 개념을 두 번 묻지 않는다.
   - 별점 4 이상을 우선한다. 오류의심 표시가 있는 문항은 절대 고르지 않는다.
   - 레슨 카드 문제와 사실상 같은 문제(같은 사실을 같은 방향으로 묻는 것)는 피한다.
   - lead = 앞 구간과 이어 주는 한 문장(25자 이내, 해요체). 사실·숫자·용어를 새로 넣지 말고
     "방금 배운 ○○, 시험에선 이렇게 나와요"처럼 레슨 제목에 있는 말만 쓴다.
2. card_refs: 레슨 문제 카드(ox·cloze·pick·match·case)마다, 같은 사실을 다루는 기출 해설 id를 0~1개 연결한다.
   - 같은 사실을 설명하는 해설만 연결한다. 비슷한 주제일 뿐이면 연결하지 않는다(null).
3. points: 레슨 끝에 보여 줄 "시험 포인트" 한 줄 기억법을 최대 3개 고른다.
   - 해설의 한 줄 기억법 문장을 그대로 쓰고, 출처 id를 붙인다. 고쳐 쓰지 않는다.
   - 이 레슨에서 가르친 내용과 관련된 것만 고른다.
4. confuse: 레슨 내용과 맞는 비교표가 있으면 출처 id 1개를 고른다(없으면 null).
5. gaps: 기출 해설에는 반복해서 나오는데 레슨 카드에는 없는 개념을 짧게 적는다(운영자 검토용, 화면에 안 나감).
6. doubts: 레슨 카드와 기출 해설의 내용이 서로 어긋나 보이는 곳이 있으면 적는다(어느 쪽이 맞는지 판단하지 말고 그대로 보고).

# 절대 규칙
- 입력에 없는 사실을 만들지 않는다. 의학 지식으로 보충하지 않는다.
- 해설 문장과 기억법은 그대로 인용하고 고치지 않는다.
- 확신이 없으면 고르지 않는다. 빈 배열과 null은 정상적인 답이다.
- 기출 원문을 재현하지 않는다(입력에 있는 다시 쓴 문항만 id로 가리킨다).
- 확인되지 않은 것을 "기출"이라고 부르지 않는다. lead에는 "시험에선"이라는 말만 쓴다.

# 출력 (JSON만, 설명 없이)
{
  "sid": "{sid}",
  "exam_cards": [ { "after": 3, "item": "c258:xo53_1_1", "lead": "방금 배운 상피 위치, 시험에선 이렇게 나와요", "why": "카드 1·2에서 장막=중피를 가르침" } ],
  "card_refs": { "2": "c258:xp53_1_1", "5": null },
  "points": [ { "m": "장막 = 중피 = 단층편평, 마찰 부위 = 중층편평", "from": "c258:xo53_1_1" } ],
  "confuse": { "from": "c258:xp53_1_1" },
  "gaps": [],
  "doubts": []
}
```

### 검증 스크립트가 자동으로 걸러 내는 것
- `item`·`card_refs`·`from`의 id가 이 스킬의 해설 목록에 없거나, 오류의심(er) 문항인 경우
- `exam_cards`가 2개를 넘거나, `after`가 범위를 벗어나거나, 두 장이 같은 구간에 들어간 경우
- `lead`가 25자를 넘거나, 레슨 제목·목표에 없는 숫자나 용어가 들어간 경우
- `points.m`이 출처 해설의 기억법과 글자 하나라도 다른 경우
- `why`가 비어 있는 경우 (사람이 검토할 때 근거를 보려고 남겨 둠)

## 7. 결정해 주실 것
1. 넣을 범위: ①~④ 전부 넣을지, ①·②만 먼저 넣을지 (추천: ①②③ 먼저, ④는 반응을 보고)
2. "시험에선" 카드 수: 레슨당 최대 2장이 괜찮은지
3. 시범 단원: 2단원(해부학) 10개 레슨으로 먼저 보여 드려도 될지
